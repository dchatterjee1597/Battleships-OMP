# Image generation prompts

Historical generation record for the original pre-rebrand design study. Names and labels in these exact prompts are retained for provenance; the implemented product now uses BATTLESHIPS. Do not regenerate images for final implementation review: use the actual-app capture helper with `--final`.

Use the built-in image_gen.imagegen tool once per job. Inspect each local reference with view_image before generation. Image 1 is the baseline; Image 2, where listed, is the generated desktop admin style anchor. Use referenced_image_paths, transparent_background: false, and the exact prompt below. Copy the resulting local PNG to Destination without resampling. Generate desktop-admin first for each theme.
